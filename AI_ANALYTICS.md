# AI / Analytics — CQA evaluator

## Selected model

Default: `gpt-5.4-mini-2026-03-17`.

Why:
- supports Structured Outputs;
- multilingual text input works for RU/KZ/EN;
- enough context for full conversations;
- lower cost than the flagship model.

The model can be changed without code:

```bash
set CQA_AI_MODEL=your-model
```

## Architecture

```
dynamic checklist + transcript with message_id
                |
                v
          system prompt v1
                |
                v
        structured LLM output
                |
                v
             validator
           /           \
        valid         invalid
          |              |
          |          one retry
          |              |
          +-------> backend adapter
                         |
                         v
              backend weighted scoring
```

AI does **not** calculate the final weighted score.

## Required environment

```bash
set OPENAI_API_KEY=...
```

Do not commit API keys.

## Output contract

Each criterion returns:

- `criterion_id`
- `applicable`
- `answer`
- `score`
- `reason`
- `evidence_ids`
- `checked_message_ids`
- `critical_error`

Evidence IDs are validated against the input transcript. Evidence text shown by
the backend is resolved from the original transcript, never generated by AI.

## N/A

- `applicable=false` only when `allow_na=true`.
- N/A score is `null`.
- A failed criterion is `applicable=true`, score 0, not N/A.

## Prompt injection

The system prompt explicitly marks transcript content as untrusted data and
forbids following instructions found inside the conversation.

## Retry

The first invalid structured answer is validated. Validation errors are returned
to the model once. If the second answer is still invalid, evaluation fails.

## Cost

Pricing snapshot used for the demo calculation:

- model: GPT-5.4 Mini
- input: $0.75 / 1M text tokens
- output: $4.50 / 1M text tokens

Before presentation, re-check official pricing:
https://developers.openai.com/api/docs/models/gpt-5.4-mini

The evaluator records real input/output token usage and calculates
`estimated_cost_usd`; it does not invent a fixed per-dialog cost.

## Prompt version

`PROMPT_VERSION = "v1"`

Change it whenever evaluation instructions materially change.
